# 🌐 Proyecto Web: Colegio Francisco de Paula Santander

¡Bienvenido! Este proyecto es la **página web oficial del Colegio Francisco de Paula Santander**.  
Está diseñado para mostrar toda la información importante del colegio de forma clara, atractiva y fácil de navegar.  

---

## 🏫 ¿Qué es este proyecto?

Es una **página web completa** que permite a estudiantes, padres, profesores y visitantes conocer:  
- 📜 La historia del colegio.  
- 📚 Programas académicos.  
- 📝 Información de admisiones.  
- 🎉 Vida estudiantil.  
- 📰 Noticias y blogs.  
- 📞 Formas de contacto.

---

## ⚙️ ¿Cómo funciona?

1. Cuando alguien visita la web (por ejemplo `www.colegiofranciscodesantander.edu`), el navegador carga el archivo **`index.html`**.  
2. Este archivo muestra el contenido principal y usa:
   - **CSS:** para aplicar los colores y el diseño. 🎨  
   - **JS (JavaScript):** para los menús, animaciones y efectos. ⚡  
   - **Imágenes y videos:** para ilustrar y hacer el sitio atractivo. 🖼️  
3. Si el visitante hace clic en otra sección (ej. "Admisiones"), se abre el archivo **`admissions.html`**.  
4. Si envía un formulario, los datos son procesados por los archivos de la carpeta **`forms/`**. 📬  

---

## 📝 ¿Para qué sirve cada parte?

- **HTML:** estructura la información. (¿Qué voy a mostrar?)  
- **CSS:** le da estilo y color. (¿Cómo lo voy a mostrar?)  
- **JavaScript (JS):** le da vida e interacción. (¿Qué pasa cuando el usuario hace clic?)  
- **Imágenes/Videos:** hacen el sitio atractivo y visual.  
- **Forms:** permiten la comunicación (mensajes, inscripciones, consultas).  

---

## 👩‍🏫 ¿Quién puede usar este proyecto?

- **El colegio:** para actualizar su información y comunicarse mejor.  
- **Estudiantes y padres:** para consultar noticias, eventos y admisiones.  
- **Profesores:** para difundir actividades.  
- **Cualquier visitante:** que quiera conocer el colegio.  

---

## 🚀 ¿Cómo puedo verlo o instalarlo?

1. Solo necesitas un navegador (Chrome, Firefox, Edge).  
2. Abre el archivo **`index.html`** haciendo doble clic.  
3. Si está publicado en internet, simplemente visita la dirección web oficial.  

> No necesitas instalar nada especial para verlo. Si eres administrador y quieres modificarlo, puedes editar los archivos con cualquier editor de texto (Visual Studio Code, Sublime, etc.).
